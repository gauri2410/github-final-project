# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

- Open an issue to report a bug, suggest an enhancement, or discuss an idea.
- Submit a pull request with a focused change and a clear description.
- Keep documentation and examples consistent with any behavior changes.
- Test your changes before submitting them.

By submitting a contribution, you agree that it will be distributed under the
terms of the project's Apache License, Version 2.0.
