# Simple Interest Calculator

A small Bash command-line calculator for computing simple interest from a
principal amount, an annual interest rate, and a time period in years.

## Usage

Run the script with Bash:

```bash
bash simple-interest.sh
```

Enter the principal, annual interest rate (as a percentage), and time in years
when prompted. The calculator displays the simple interest and the total amount.

The calculation is:

```text
simple interest = principal * rate * time / 100
```
